Q1 Define Vector Space.

A non-empty set $V$ is called a vector space over a field $F$ with respect to vector addition ($+$) and scalar multiplication ($\cdot$), denoted as $V(F)$, if for all vectors $u, v, w \in V$ and scalars $lpha, eta \in F$, the following 10 axioms hold:

I. Axioms for Vector Addition ($(V, +)$ is an Abelian Group):
  • Closure: $u + v \in V$
  • Associative Law: $(u + v) + w = u + (v + w)$
  • Additive Identity: $\exists\, 0 \in V$ such that $u + 0 = 0 + u = u$
  • Additive Inverse: $\exists\, -u \in V$ such that $u + (-u) = (-u) + u = 0$
  • Commutative Law: $u + v = v + u$
II. Axioms for Scalar Multiplication:
  • Closure: $lpha \cdot u \in V$
  • Distributive over vector addition: $lpha(u + v) = lpha u + lpha v$
  • Distributive over scalar addition: $(lpha + eta)u = lpha u + eta u$
  • Scalar Associativity: $(lpha eta)u = lpha(eta u)$
  • Unit scalar identity: $1 \cdot u = u$ (where $1 \in F$ is the multiplicative identity).
Q2 State and prove the cancellation law for vector addition.

Statement: In any vector space $V(F)$, if $x, y, z \in V$ such that $x + z = y + z$, then $x = y$.

Proof: Since $z \in V$, there exists an additive inverse $-z \in V$ such that $z + (-z) = 0$.

$$egin{aligned} x &= x + 0 = x + (z + (-z)) && ( ext{Identity \& Inverse}) \ &= (x + z) + (-z) && ( ext{Associative Law}) \ &= (y + z) + (-z) && ( ext{Given: } x + z = y + z) \ &= y + (z + (-z)) && ( ext{Associative Law}) \ &= y + 0 = y \end{aligned}$$

Hence proved: $x = y$
Q3 If $V = \mathbb{R}^3$, verify whether $W = \{(a_1, a_2, a_3) \mid 2a_1 - 7a_2 + a_3 = 0\}$ is a subspace.

Step 1: Zero Vector Check: For $(0, 0, 0)$:

$$2(0) - 7(0) + (0) = 0 \implies (0,0,0) \in W$$

Step 2: Linear Combination Check: Let $u = (a_1, a_2, a_3) \in W$ and $v = (b_1, b_2, b_3) \in W$, so $2a_1 - 7a_2 + a_3 = 0$ and $2b_1 - 7b_2 + b_3 = 0$. For any scalars $lpha, eta \in \mathbb{R}$:

$$egin{aligned} &2(lpha a_1 + eta b_1) - 7(lpha a_2 + eta b_2) + (lpha a_3 + eta b_3) \ &= lpha(2a_1 - 7a_2 + a_3) + eta(2b_1 - 7b_2 + b_3) \ &= lpha(0) + eta(0) = 0 \end{aligned}$$

Since $lpha u + eta v \in W$ for all $lpha, eta \in \mathbb{R}$ and $u, v \in W$:

$W$ is a subspace of $\mathbb{R}^3$
Q4 Define Subspace.

Let $V$ be a vector space over a field $F$. A non-empty subset $W$ of $V$ is called a subspace of $V$ if $W$ is itself a vector space over $F$ under the operations of vector addition and scalar multiplication defined on $V$.

Subspace Criterion: A non-empty subset $W \subseteq V$ is a subspace iff:

1. $0 \in W$

2. $lpha u + eta v \in W$ for all $u, v \in W$ and all scalars $lpha, eta \in F$.

Q5 Define Linear Combination.

Let $V$ be a vector space over a field $F$ and $S = \{v_1, v_2, \dots, v_n\}$ be a non-empty subset of $V$. A vector $v \in V$ is said to be a linear combination of the vectors in $S$ if there exist scalars $c_1, c_2, \dots, c_n \in F$ such that:

$$v = c_1 v_1 + c_2 v_2 + \dots + c_n v_n = \sum_{i=1}^n c_i v_i$$
Q6 Determine whether $v_1=(1,-2,3), v_2=(5,6,-1), v_3=(3,2,1)$ are Linearly Dependent or Independent in $\mathbb{R}^3$.

Form the $3 imes 3$ matrix $A$ using the given vectors as row vectors:

$$|A| = egin{vmatrix} 1 & -2 & 3 \ 5 & 6 & -1 \ 3 & 2 & 1 \end{vmatrix}$$ $$egin{aligned} |A| &= 1[6(1) - (-1)(2)] - (-2)[5(1) - (-1)(3)] + 3[5(2) - 6(3)] \ &= 1(6 + 2) + 2(5 + 3) + 3(10 - 18) \ &= 1(8) + 2(8) + 3(-8) = 8 + 16 - 24 = 0 \end{aligned}$$
Since $|A| = 0$, the vectors are Linearly Dependent (LD).
Q7 Define Basis.

A subset $S$ of a vector space $V$ is called a basis of $V$ if it satisfies two conditions:

1. $S$ is linearly independent.

2. $S$ spans $V$, i.e., $\operatorname{Span}(S) = V$ (every vector in $V$ can be expressed as a linear combination of vectors in $S$).

Q8 Find the dimension of $W$, where $W = \{(x_1, x_2, x_3) \mid x_1 + x_2 + x_3 = 0\}$.

Given the condition: $x_1 + x_2 + x_3 = 0 \implies x_1 = -x_2 - x_3$.

Any vector in $W$ can be written as:

$$egin{aligned} (x_1, x_2, x_3) &= (-x_2 - x_3, x_2, x_3) \ &= x_2(-1, 1, 0) + x_3(-1, 0, 1) \end{aligned}$$

The set $\{(-1, 1, 0), (-1, 0, 1)\}$ is linearly independent and spans $W$.

Since the basis contains 2 vectors, $\dim(W) = 2$ (Formula: $n - k = 3 - 1 = 2$).
Q9 Is the set $\{(1,2,1), (2,1,0), (1,-1,2)\}$ Linearly Independent or Dependent?

Evaluate the determinant of the matrix formed by the vectors:

$$|A| = egin{vmatrix} 1 & 2 & 1 \ 2 & 1 & 0 \ 1 & -1 & 2 \end{vmatrix}$$ $$egin{aligned} |A| &= 1(2 - 0) - 2(4 - 0) + 1(-2 - 1) \ &= 1(2) - 2(4) + 1(-3) = 2 - 8 - 3 = -9 eq 0 \end{aligned}$$
Since $|A| = -9 eq 0$, the set is Linearly Independent (LI).
Q10 If $V = A \oplus B$, show that $\dim V = \dim A + \dim B$.

By the dimension formula for the sum of two subspaces:

$$\dim(A + B) = \dim A + \dim B - \dim(A \cap B)$$

Since $V = A \oplus B$ (Direct Sum), by definition:

1. $V = A + B \implies \dim(A + B) = \dim V$

2. $A \cap B = \{0\} \implies \dim(A \cap B) = 0$

$$\dim V = \dim A + \dim B - 0 \implies \dim V = \dim A + \dim B$$
Hence proved: $\dim V = \dim A + \dim B$
