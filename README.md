# 📘 LANA • Unit 1: Vector Spaces (Master Study Web App)

A modern, responsive, claymorphic & neumorphic web application built for **23MA1302 — Linear Algebra & Numerical Analysis** (Panimalar Engineering College Autonomous, Anna University R2021 ECE).

---

## ✨ Features
- **Claymorphic & Neumorphic Minimal UI:** Soft diffused dual shadows, pastel ice-blue and white gradients, and tactile 3D elements.
- **Zero Math Input Errors:** Powered by **KaTeX** with vector math typesetting for all determinants, matrices, Greek letters ($\alpha, \beta$), and sums.
- **Interactive "💡 Why We Do This Step" Dropdowns:** Touch/click any explanation accordion to see why each mathematical step and formula is used.
- **Part A & Part B Tabs:**
  - **Part A (2-Mark Questions):** All 10 compulsory Question Bank questions (Vector space 10 axioms, Cancellation law proof, Subspaces, Linear combinations, Independence test, Basis, Dimension).
  - **Part B (16-Mark Questions):** Core exam-oriented proofs and row-echelon reductions with deep step-by-step reasoning.
- **Filter Chips:** Quickly filter questions by *Axioms*, *Subspaces*, *Linear Independence*, or *Basis & Dimension*.

## 🚀 How to Run & Push to GitHub Pages

### 1. Run Locally
Simply double-click or open `index.html` in any web browser (Chrome, Edge, Safari, Firefox).

### 2. Deploy to GitHub Pages
1. Push `index.html` to a new GitHub repository:
   ```bash
   git init
   git add index.html README.md
   git commit -m "Add LANA Unit 1 Vector Spaces Web App"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Your study web app will be live on `https://<your-username>.github.io/<your-repo-name>/`!
